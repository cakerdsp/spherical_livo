# 当前模型与实现边界

本实现是 FAST-LIVO2 原版 VIOManager 内的球面观测替换；主节点、IMU、LIO 和视觉更新公式来源见 restoration_scope.md。

## 采样与 warp

原始相机标定生成 `(u,v) -> b` 单位射线 LUT。像素网格只供存储、检索、特征候选筛选和显示；没有生成虚拟相机或切平面图像。固定 Fibonacci 球冠节点（含中心）在建立参考时定向，节点数和角半径由已有三个 visual 配置项控制。

参考特征保存源相机球面图像、方向、参考位姿。局部有限平面来自原版雷达体素地图。对参考方向 `b_rk`，计算 `P_rk = h b_rk / (n_r^T b_rk)`，再由同一刚体状态得到 `b_ck = normalize(R_cr P_rk + t_cr)`。所有采样点共同约束一个状态，不逐点估计自由位移。

球面亮度使用固体角加权、紧支撑 Wendland 核插值，梯度对同一表达式求导并投影到球面切空间。切空间用于微分计算，不用于构造图像。球面 warp 的微分将参考滤波圆映射成当前滤波椭圆，同时考虑两台相机的原生角分辨率。保留原版粗到细调用，默认 4、2、1 三档滤波尺度；每级初始固定参考值和核矩阵，迭代时不靠丢点降低残差。

全部采样及滤波支持需落在测得的有限平面范围；当前 LiDAR 点在整个 patch 范围内与平面预测射线距离进行 3 sigma 一致性检查。拒绝有深度断层证据、无可靠平面、完整滤波支持越界或饱和／欠曝的观测。稀疏雷达无法发现所有无测量遮挡；局部平面、静态场景和中心相机仍是假设。

## 状态与光度更新

固定 19 维：旋转 0–2、平移 3–5、逆曝光 6、速度 7–9、陀螺偏置 10–12、加速度偏置 13–15、重力 16–18。恢复原版 IMU/LIO 索引、状态加减与传播。

观测 `e_k = tau_c I_c(b_ck) - tau_r I_r(b_rk)`。亮度按原版 0–255 量纲；只把原像素梯度乘投影雅可比替换为球面梯度乘归一化方向雅可比，继续使用原版 7 列观测、19 维先验与 IEKF 公式。没有独立 20 维估计器。多相机顺序更新同一状态和共享地图，历史参考可以来自任意相机；每台相机缓存自己的逆曝光初值，切换时使用独立的曝光先验。

参考选择沿用原版基于相机中心的近视角选择；删除不再适用于不同物理球冠域的原始 patch 两两 NCC 比较。保留原版观测维护和法向收敛流程。

当前使用原版灰度观测噪声与 patch 残差拒绝门限；没有旧独立估计器的联合白化、Huber、线搜索或精确相关性建模。插值和平面引入的相关性按原版条件地图近似处理，不宣称完整联合 SLAM 后验。非线性响应、暗角、视角反光、专门前向弱观测抑制仍为 TODO。

## 同步与并行

主节点沿原版顺序链：等待完整图像组及雷达／IMU覆盖 → 在组时间完成 LIO → 紧接 VIO。多相机组帧取自 cake_slam，固定时间偏移后在容差内配对，使用组内最大时间；不会声称容差内图像严格同步。原版 LIO 匹配、球面残差逐 patch 计算、着色逐点计算使用 OpenMP；状态和地图更新始终顺序执行。

仅完成源码及基本静态核对；精度、收敛与实时性能尚未通过部署回放验证。


## 性能实现（2026-09-28）

保持既有 patch 上限、节点数、角半径、尺度、局部平面检验与 IEKF 顺序。原生相机解析投影仅为 LUT 单元定位提供初值，必须通过原有球面三角形包含检查；无法定位时仍走 KD 搜索。没有把球面 patch 改回像素／虚拟平面 patch。

参考方向的原生角间隔与切空间基在创建时缓存。2×2 warp 的奇异值用等价闭式表达式求出，核矩阵和最大支持半径在每次线性化前准备；迭代内不再重复特征值分解。每级开始时，同位姿复用已准备的 warp 及当前亮度／球面梯度；与缓存位姿不同时重新准备该级。级内迭代重新采样当前亮度与梯度，参考亮度和滤波矩阵仍按级固定。

采样器不再为视觉更新构造未使用的逐像素权重数组。有限平面检验先用射线与平面交点变化的保守上界，证明整个核支持位于平面内时省去逐像素检查；不能证明时仍逐像素检查，未放宽边界。当前雷达方向建单元索引，每个 patch 查询覆盖球冠相交的单元，再执行相同距离及 3 sigma 检验；没有抽稀雷达深度。

采用 cake_slam 的独立结果槽与顺序汇总方式：patch 筛选、分层准备、残差、新参考构造并行；地图插入、观测删除、相机顺序和滤波状态更新串行。异常在线程内捕获，汇合后重新抛出。按运行环境自动使用至多 8 个视觉工作线程，无新增 YAML 调参项。原版 IMU/LIO 保持不变。

每路表增加 preparePatches，包含先前未列出的分层准备耗时；Current Total Time 也包含图像准备、深度索引和绘图。主节点新增 Multi-camera VIO Time：All Cameras 是整个相机组顺序处理墙钟时间（含各路表输出），另列 RGB/Image 发布、Group Total 与 Group Average。不能用单路时间或剔除准备时间来声称达到双路 30 ms。

30 ms 是双路处理目标，未在本地编译或回放，不能由源码优化推定达标。新增几何快速路径回归用例源文件，本次没有执行测试。

## 全局构造前选点

每个相机分别从当前 LiDAR 覆盖的局部视觉地图收集视野内候选。保留平面与参考有效性初筛，取消像素网格的每格代表点、每格名额和最近点竞争；所有合格候选按当前原图 Shi–Tomasi 分数全局取前 max_patches 个。新建点也从可见的雷达候选中全局取前 max_patches - total_points 个。仅排除完全相同的三维位置以防重复入图，不进行邻近点压制。全局指每相机当前候选池，不是扫描整张历史地图，也没有跨相机抢占预算。

评分只用于挑选候选，不进入球面残差或 IEKF 权重。分数相同时按世界坐标决定，选中结果也按坐标顺序汇总，避免 unordered_map 遍历顺序影响累加。原有 grid_size/grid_n_height 主节点参数为兼容入口保留，不再影响视觉候选选择；无需修改 YAML。

没有第二套构造后光度误差排名，也没有将中心单点光度误差设为唯一排序标准。低中心误差可能来自平坦区域或偶然同亮度，不代表完整 patch 的一致性、梯度信息或位姿约束强度。若以后引入该代理量，应比较经曝光补偿、指向同一三维位置的两路中心强度，不能将已平滑的参考 patch 中心直接与未经匹配滤波的当前原始像素当作同一个残差。

max_patches 同时限制昂贵构造尝试数量，失败后不继续补满；最终点数可能少于原补满策略。全局纹理排名可能集中在高纹理区域，不保证空间分布或几何观测条件改善。表内 Eligible Candidates 是平面／参考有效候选，Selected Candidates 是构造前选中数，Accepted Patches 是完整检查通过的优化点。

## 几何前移与多尺度复用

球面准备明确分为：全部采样方向的射线与平面求交、角度 warp 与核范围 → 深度一致性 → 图像采样与完整支持检查 → 光度误差。单尺度重线性化、新建参考和参考更新也通过这一顺序，任何深度失败都发生在亮度采样之前。有限平面上的采样中心、退化 warp、核半径界限在几何阶段拒绝；涉及实际贡献像素的有限支持、图像边界、饱和及欠曝检查仍保留在采样器中。

同一候选的金字塔只计算一次粗尺度几何。细尺度复用三维交点、当前方向和 warp 微分，将核半径乘以 2 的尺度差次幂、核矩阵除以其平方。深度检验使用的粗尺度包络包含所有细尺度支持，因此只查一次粗尺度范围，不减小检查范围、不改变 3 sigma 判据；各尺度亮度仍独立采样。状态更新导致位姿变化时重新准备该级几何。

工作任务较少时 OpenMP 分块由 4 个 patch 改为 1 个，线程数不超过任务数；单任务直接串行计算。相机和状态依旧顺序执行。本次只做基本源码检查，未编译或回放；全局选点的点数、地图规模、精度和耗时变化均需部署验证。
