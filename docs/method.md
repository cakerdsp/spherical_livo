# 模型与实现约定

## 图像域和插值

每个中心相机的原生像素 `(u,v)` 预计算单位方向 `r_uv` 和固体角面积权重。保留原像素邻接关系，方向索引通过稀疏 KD 树与局部球面三角形包含检查定位；图像网格仅用于存储和查找，没有构造切平面图像。

球面亮度场由紧支撑 Wendland 核重建：

`I(b; A) = sum_i omega_i K(sqrt((b-r_i)^T A (b-r_i))) I_i / sum_i omega_i K(...)`

其中 `K(q)=(1-q)^4(4q+1)`，`0<=q<1`，其余为零。面积 `omega_i` 来自射线 LUT 的局部固体角。核支持边界的值和一阶导数均为零。梯度对该同一归一化表达式求导，然后用 `I-bb^T` 投影到球面切空间。切空间只用于微分和椭圆的表示，不用于生成图像。

每个插值支持在读值前检查原始饱和与欠曝码值；遇到无效像素、图像／参考块边界或不完整支持时返回无效，不补零、不跨越边界插值。

## patch、场景支持与 warp

参考域采用固定确定性 Fibonacci 球冠节点，包含中心方向；球冠在建立参考时定向，后续优化不重新生成节点。角半径是参考观测域大小，不是固定的物理表面积。

对参考平面 `n_r^T X_r=h`：

`d_k = h/(n_r^T b_rk)`，`P_rk=d_k b_rk`。

保存世界点、参考方向和参考传感器图像块。整块 patch 共享一个刚体状态：

`b_ck = normalize(R_cr P_rk+t_cr)`。

这在给定局部平面下是逐采样点的完整几何 warp，不是中心点的二维仿射近似，也不是每个点独立优化。正深度以射线距离判断，鱼眼可见方向不因 `z<=0` 被统一排除。

平面支持来自 LiDAR 体素地图。patch 及其低通支持必须落在所测有限平面范围内。已有雷达深度按当前相机方向与平面预测的射线距离比较，门限使用深度／平面不确定性。比较覆盖完整采样和滤波范围。

**稀疏深度检查不能保证发现没有雷达观测到的细小遮挡。** 系统采用局部静态表面和中心相机假设；没有将所有现实表面宣称为平面。

## 尺度与成像带宽

参考球面到当前球面的微分将参考滤波圆变换为当前滤波椭圆。滤波尺寸至少覆盖参考和当前的原生角分辨率，因此缩小时会同时降低可比较的参考频带。整个 patch 不引入独立的平移、旋转或缩放拟合变量。

使用 `4,2,1` 三个固定滤波尺度，采样节点始终固定。每级以该级初始状态固定滤波形状和参考值，级内对同一目标函数求导，支持不完整的候选步拒绝接受。尺度通过球面微分选择，而不是由用户设置像素金字塔。

带宽匹配使用局部微分，是有限滤波支持在非线性 warp 下的一阶近似；传感器本身已丢失的高频不能被恢复。核搜索超过有限范围或变形超过可用参考支持时，观测明确无效。

## 状态、曝光与更新

惯性状态为 18 维：右扰动旋转、世界平移、速度、陀螺仪偏置、加速度偏置、重力。外参和时间偏移固定。沿用 FAST-LIVO2 的离散 IMU 噪声传播约定。

每个图像事件增加一个帧级 log gain `a`，所有 patch 共享：

`e_k = exp(a) I_c(b_ck) - gain_ref I_r(b_rk)`。

初始化或无可用视觉约束时，使用该相机上次的 gain（初值 1）；因此完全无共同参考的相机亮度比例并非已被标定。复杂响应／暗角等仍属于研究 TODO。未加入每 patch 的自由亮度模型。

优化包含传入惯性／雷达状态的先验。SO(3) 先验残差使用右雅可比逆转换，投影 Jacobian 从三维点归一化直接求得。曝光与位姿联合解算；最终从联合信息矩阵求状态边缘协方差，保留消去曝光所损失的信息。

粗到细各级都使用同一个输入先验，协方差仅在最终成功级更新一次，避免多尺度反复计算同一图像的信息。线搜索使用固定白化、固定 patch 集合；不能通过丢掉难匹配点降低代价。

## 噪声、相关性与近似

原图噪声从 2×2 高频差分的 MAD 估计，使用一个灰度级的下限。纹理可能使该估计偏保守，不等同于完整传感器噪声标定。

每个 patch 内，插值原像素权重构成 `R_image = sigma_c² W_c W_c^T + sigma_r² W_r W_r^T`，包含参考 gain 和当前 gain。共享平面的不确定性通过 `J_plane Sigma_plane J_plane^T` 加入同一 patch 协方差。使用 Cholesky 白化后的 Huber 损失。

选用当前图像内不相交的 patch 支持以减少重复信息。历史参考、不同 patch 之间的地图关联，以及雷达／视觉共用地图产生的跨观测相关性，仍按条件地图近似处理；没有宣称这是完整联合 SLAM 后验。参考姿态在该次视觉更新中固定。

## 工程常数

这些常数集中于相关实现处，具有明确作用，不代表“零超参数”：

| 常数 | 用途 |
| --- | --- |
| 原生核半径下限 2.5 个局部角间隔 | 连续插值和滤波支持 |
| Huber 1.345 | 白化高斯残差的常用稳健效率选择 |
| 深度检验 3 sigma | 基于给定几何误差模型的门限 |
| 平面支持 3 倍拟合半径 | 限制平面外推 |
| 8 次优化、最多 1/64 步长回退 | 有界非线性求解 |
| 参考原图块 64 像素余量、查询半径最多 128 像素 | 有限存储／计算；超限拒绝而非截断核 |
| 视觉点容量 32 × 单次 patch 预算 | 基本内存上限 |

这些设置需要后续真实数据验证；本次未编译或执行。
