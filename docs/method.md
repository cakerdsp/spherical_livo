# 当前模型与实现边界

本实现是 FAST-LIVO2 原版 VIOManager 内的球面观测替换；主节点、IMU、LIO 和视觉更新公式来源见 restoration_scope.md。

## 采样与 warp

原始相机标定生成 `(u,v) -> b` 单位射线 LUT。像素网格只供存储、检索、特征候选筛选和显示；没有生成虚拟相机或切平面图像。固定 Fibonacci 球冠节点（含中心）在建立参考时定向，节点数和角半径由已有三个 visual 配置项控制。

参考特征保存源相机球面图像、方向、参考位姿。局部有限平面来自原版雷达体素地图。对参考方向 `b_rk`，计算 `P_rk = h b_rk / (n_r^T b_rk)`，再由同一刚体状态得到 `b_ck = normalize(R_cr P_rk + t_cr)`。所有采样点共同约束一个状态，不逐点估计自由位移。

球面亮度现在使用 LUT 射线三角形插值。原相机解析投影仅定位原图/尺度层单元，四个角点的射线划分为固定两个三角形，包含目标方向的三角形提供三个强度值。令 R 为三个顶点射线组成的矩阵，a=R^{-1}b，w=a/(1^T a)，I(b)=w^T I_vertices。梯度由同一表达式解析求出并投影到球面切空间。共享边的权重一致，亮度连续；梯度是分片的，不保证跨三角形 C1 连续。没有虚拟相机或切平面图像，原像素只用于索引。

每帧一次构建原传感器坐标的浮点预滤波金字塔，递归使用 5-tap binomial 核与固体角权重，并二倍下采样。第 L 层的射线仍从原 LUT 的 (2^L x,2^L y) 读取；标定相关的权重质量和滤波支持包络只构建一次。每次采样只取一个三角形的 3 个值；混合相邻尺度时最多 6 个值。灰度和梯度使用相同冻结的尺度与混合系数。

原有 warp 角度微分用于将参考滤波范围变换到当前方向。将局部角协方差变换到原像素度量后，以最大特征值选择预滤波尺度，混合系数按名义方差匹配。为了衔接已有带宽规则，原半径 r 换算为局部协方差 (5/72)r^2，来自二维 Wendland 核的每轴二阶矩。随后使用的是新的传感器金字塔模型，不再逐查询执行 Wendland 核滤波。固体角权重和非线性投影使该方差对应关系属于局部近似。

原图尺度层为各向同性传感器滤波，按较大轴选择带宽以降低欠滤波风险；强各向异性时可能过度模糊较小轴，参考/当前滤波不再精确对应原来的椭圆核。不能声称数值等价或消除了所有混叠。三级视觉优化仍保留，实际尺度选择同时考虑两台相机原生分辨率与 warp。

预滤波的每个正权重贡献像素必须有效，任一饱和、欠曝、无效 LUT 或越界贡献会向高层传播无效标记。有限平面检查覆盖完整预滤波支持：预计算球冠界能证明包含时直接通过，不能证明时检查实际原像素支持框内的射线。这是几何边界检查的精确后备路径，不进行大邻域亮度加权。各尺度实际支持的包络并集用于 LiDAR 3 sigma 深度一致性检查。静态场景、中心相机和局部有限平面仍是假设，稀疏雷达无法发现所有无测量遮挡。

## 状态与光度更新

固定 19 维：旋转 0–2、平移 3–5、逆曝光 6、速度 7–9、陀螺偏置 10–12、加速度偏置 13–15、重力 16–18。恢复原版 IMU/LIO 索引、状态加减与传播。

观测 `e_k = tau_c I_c(b_ck) - tau_r I_r(b_rk)`。亮度按原版 0–255 量纲；只把原像素梯度乘投影雅可比替换为球面梯度乘归一化方向雅可比，继续使用原版 7 列观测、19 维先验与 IEKF 公式。没有独立 20 维估计器。多相机顺序更新同一状态和共享地图，历史参考可以来自任意相机；每台相机缓存自己的逆曝光初值，切换时使用独立的曝光先验。

参考选择沿用原版基于相机中心的近视角选择；删除不再适用于不同物理球冠域的原始 patch 两两 NCC 比较。保留原版观测维护和法向收敛流程。

当前使用原版灰度观测噪声与 patch 残差拒绝门限；没有旧独立估计器的联合白化、Huber、线搜索或精确相关性建模。插值和平面引入的相关性按原版条件地图近似处理，不宣称完整联合 SLAM 后验。非线性响应、暗角、视角反光、专门前向弱观测抑制仍为 TODO。

## 同步与并行

主节点沿原版顺序链：等待完整图像组及雷达／IMU覆盖 → 在组时间完成 LIO → 紧接 VIO。多相机组帧取自 cake_slam，固定时间偏移后在容差内配对，使用组内最大时间；不会声称容差内图像严格同步。原版 LIO 匹配、球面残差逐 patch 计算、着色逐点计算使用 OpenMP；状态和地图更新始终顺序执行。

仅完成源码及基本静态核对；精度、收敛与实时性能尚未通过部署回放验证。


## 性能实现

原来的查询时大邻域 Wendland 权重循环、特征值分解和逐像素梯度累加已经删除，只有一套三角形采样路径。图像准备新增一次预滤波成本，金字塔总像素数约为原图的 4/3；浮点强度、有效掩码及标定支持信息会增加内存。不能只看 computeJacobian 降低而忽略 image/depth index 和总耗时。

参考方向、角间隔与切空间基在创建时缓存；粗细尺度复用射线交点、当前方向和角度 warp 几何。像素滤波尺度在每级初始准备后冻结，迭代中只改变查询方向，亮度梯度与实际使用的插值严格对应，不对冻结的尺度选择求导。

patch 准备、残差和参考构造按独立结果槽并行；地图、相机和滤波状态顺序更新。少任务时采用单 patch 分块，单任务串行。Current Total Time 包含图像准备、深度索引和绘图；Multi-camera VIO Time 的 All Cameras 是相机组顺序处理墙钟时间，Group Total 还包含着色及图像发布。30 ms 是双路目标，尚无本地编译或回放结果。

## 网格候选与全局构造前选点

每个相机分别从当前 LiDAR 覆盖的局部视觉地图收集视野内候选，经平面与参考有效性初筛后，沿用上游的每格最近地图点作为代表；再按当前原图 Shi–Tomasi 分数全局取前 max_patches 个格子代表进行球面 patch 构造。新建点先避开可见地图点占据的格子，再在每个空格保留纹理分数最高的雷达候选，最后全局选取 max_patches - total_points 个代表。占用格在 EKF 更新后重新投影计算。保留完全相同三维位置的去重。

vio/grid_size > 10 时直接作为像素格边长；否则使用 max(1, image_height / vio/grid_n_height)，默认 grid_size=5、grid_n_height=17。各相机按自身分辨率计算，配置值不会因切换相机而改变；边缘不足一格的部分也计入。网格用于分散候选，球面 patch 的采样、warp 和雅可比保持不变。相邻格边界仍可能出现近邻点，网格不保证 patch 完全不重叠，也不保证全图均匀覆盖。

全局 Top-K 指每相机格子代表池，不扫描整个历史地图，也没有跨相机争抢预算。每格比较及全局评分出现并列时按世界坐标决定，选中结果按坐标顺序汇总。评分只用于候选选择，不进入球面残差或 IEKF 权重；没有新增中心单点光度误差排序。

max_patches 仍限制昂贵构造尝试次数，失败后不继续补满。表内 Eligible Candidates 是网格筛选前的平面／参考有效候选，Grid Candidates 是每格代表数，Selected Candidates 是全局 Top-K 构造尝试数，Accepted Patches 是完整检查通过的优化点。恢复网格后候选更分散，但不承诺接受点数或耗时改善。

## 几何前移与多尺度复用

准备顺序为：射线/平面求交、角度 warp → 各尺度三角形与完整预滤波支持有效性 → 所有尺度包络并集的深度检查 → 强度与解析梯度 → 光度检查。新参考和每级重线性化使用同一顺序。由于新的预滤波三角形会随尺度改变，不再直接假定细尺度贡献集合一定包含在粗尺度内；显式取各尺度包络最大值。

三角形梯度、跨边连续性、滤波饱和传播、有限平面支持和后半球采样的回归用例已更新。本次只做基本源码检查，没有执行这些测试、编译或回放。点数、精度、内存和实时性仍需部署验证。
