# 已明确暂缓的研究问题

这两项不包含占位实现、运行开关或声称已经完成的机制。

1. **复杂光度差异**：相机非线性响应、空间暗角和视角相关反光。先评估残差与亮度、图像位置、相机组合的关系，再决定是否引入空间／响应模型。饱和支持检查和基础曝光估计已属于核心实现，不在此 TODO 内。
2. **前后运动下的专项弱观测处理**：在实际光度模型、曝光消元和噪声处理之后评估方向信息，研究需要何种降权或拒绝。不得直接假设全部前进运动都弱观测，也不得仅修改状态增量而不处理协方差。频域方法仅作为尚待验证的研究方向。

不纳入当前功能范围：在线外参、在线时间偏移、旧光流／虚拟平面前端、高级视觉地图管理、方向性更新。
